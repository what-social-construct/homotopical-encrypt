# Output locations

The canonical manuscript sources and compiled PDFs live together under
`papers/paper1/` and `papers/proximity-prize/`. Paper 2 is a working text draft.

For local reading, use only the current copies in `output/pdf/`:
`homotopical-encryption-proofread.pdf` and
`capacity-radius-proximity-proofread.pdf`.

| Location | Purpose |
|---|---|
| `output/packages/palomar/` | Three slim entry trees and ZIPs, generated by `scripts/export_palomar_entries.py`. |
| `output/packages/human-review/` | Broad Lean/manuscript review tree and ZIP, generated by `scripts/export_public_review.py`. |
| `output/validation/` | Current local build, comparison, dependency and layout checks. |
| `output/archive/` | Older reports, releases, PDFs and render checks, preserved as historical evidence. |

A review bundle includes its own PDF and TeX so it can be reviewed independently.
Those copies are generated artifacts. Revise the canonical manuscript, then
refresh the reading copy and bundles. The output tree is ignored by Git.

The archived runtime tree at `archive/runtime/` is separate from these outputs
and is excluded from review packages. No package generation publishes or
submits anything.
