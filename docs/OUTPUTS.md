# Output locations

The canonical manuscript sources and compiled PDFs live together under
`papers/paper1/` and `papers/proximity-prize/`. Paper 2 is a working text draft.

Read the canonical PDFs directly: [Paper 1](../papers/paper1/main.pdf) and
[Paper 3](../papers/proximity-prize/main.pdf). There is no separate reading-copy
directory under `output/`.

| Location | Purpose |
|---|---|
| `output/packages/palomar/` | Three slim entry trees and ZIPs, generated by `scripts/export_palomar_entries.py`. |
| `output/packages/human-review/` | Broad Lean/manuscript review tree and ZIP, generated by `scripts/export_public_review.py`. |
| `output/validation/` | Current local build, comparison, dependency and layout checks. |
| `archive/output/` | Older reports, releases, PDFs and render checks, preserved as historical evidence. |

A review bundle includes its own PDF and TeX so it can be reviewed independently.
Those copies are generated artifacts. Revise and compile the canonical
manuscript, then refresh its bundles. The output tree is ignored by Git.

Historical outputs live under the main `archive/` directory alongside the
runtime prototypes at `archive/runtime/` and earlier documentation at
`archive/documentation/`. Archives are excluded from review packages. No
package generation publishes or submits anything.
