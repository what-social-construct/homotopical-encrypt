formalization but are no longer part of the active proof surface.

## Wrapper/Fibration Experiments

exploratory category-theory probes for the tagged wrapper category used by
`Hardness.lean`.

The useful content now lives in:

- `Hardness.Wrapper`
- `Hardness.FibrationCopy`
- `Hardness.ToWrapper`
- `Hardness.FromWrapper`
- `Hardness.copy_equivalent_thm`
- `Hardness.FibrationCopy_is_Grothendieck`

These files remain here only as proof-search archaeology.
