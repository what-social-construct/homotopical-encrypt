## Scope and current assessment

The paper has a substantial proved coding core. Its main results are:

1. For every injectively indexed RS code with `1 ≤ k ≤ n` and every positive
   interleaving width, the worst list size at count radius `n-k` is exactly
   `choose(n,k)`. The fractional endpoint target is equivalent to its binomial
   field-size budget. An explicit next-shell list has size at least `q^m`.
2. For the two-coordinate, same-set MCA experiment, every received pair and
   every real radius satisfy `|Bad| ≤ choose(n,k+1)`. This is a sufficient
   field-size certificate, not an exact spectrum formula for every code.
3. The rate-quarter family `n=256·2^u`, `k=64·2^u`, `q=3^n` meets the two
   `2^-128` budgets. Lean now constructs `GaloisField 3 n`, the exact
   order-`n` multiplicative subgroup and its injective power domain for every
   `u`. The full list and MCA family endpoints require no supplied realization.
4. The distinct boundary-field code `q=2^128+192513`, `n=4096`, `k=1024`
   has a concrete Lean field/domain construction and an exact MCA grid
   transition: greatest safe count radius `0`, first unsafe count radius `1`,
   real safe interval `[0,1/4096)` and its nonattained supremum.
5. A neutral application interface proves source-far implies target-far from
   a supplied pointwise comparison. Outside the standalone import closure,
   the actual public cochain projection already has a canonical pair-distance
   equality and all-radius calibration for its verifier-facing pullback
   metric. The new systematic modular source now has its own intrinsic valid
   locus and independently defined native scalar-coordinate distance. Actual
   lifts prove `d_C ≤ d_P = D_RS ≤ 2d_C`; an upstream Euclidean/frame/HCP score
   remains a different comparison problem.

### Status and role vocabulary

- **exact**: the same object or statement is represented; any claimed theorem
  is proved with the displayed hypotheses. A universal bound plus an attaining
  witness may characterize a maximum without introducing a second object.
- **parameterized**: Lean proves the result after an explicit input which
  the paper constructs or an application must supply.
- **missing**: the paper defines, proves, or uses the item, but the standalone
  Lean surface does not contain that item or complete theorem.
- **not identified**: an abstract interface exists, but no theorem identifies
  it with the paper's concrete mathematical object.

Roles are independent: **CORE** is part of the coding result, **INSTANCE** is
a selected field/domain, **APPLICATION** is downstream, **ADAPTER** changes
presentation, and **PROOF** is an internal witness or counting construction.
A missing wrapper is not an open mathematical problem. No
declaration or compatibility layer is proposed for deletion by this audit.

Disposition is independent of proof status: canonical objects stay
**CANONICAL**, lossless conversions stay **ADAPTER**, and proof-only wrappers
stay **PROSE ONLY** unless the manuscript actually names their objects.
Valid older ordered certificates remain **RETAIN**; an improvement in their
bound does not make their underlying objects false or obsolete.
